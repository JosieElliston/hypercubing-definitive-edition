# Changes

## 1.0

First release, for Mac and Linux, with 19 programs:
MagicTile, pCubes, MC7D-KB, Magic Puzzle Ultimate, Magic Simplex 5D, Magic Hyperbolic Tile,
Magic Cube 5D, Magic120Cell, Magic Cube 4D, Eleven Cell, ElevenCell3D, Magic Cube 3D,
IsoCubeSim, Gelatinbrain, Hyperspeedcube 1, Hyperspeedcube 2, circleguy, 3to4++ and Geraniums Pot.
The Linux edition needs Wine installed on your system; see its README. circleguy, 3to4++ and
Geraniums Pot run as their Windows versions there.
